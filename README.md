# FiscalShop — Веб-сайт для продажи фискальных накопителей с оплатой через Bitcoin Core

## Описание

Веб-сайт для продажи фискальных накопителей с приемом оплаты в Bitcoin (BTC) через Bitcoin Core.


### Функционал:

- **Главная страница** с информацией о товаре и преимуществах
- **Оформление заказа** (форма: ФИО, телефон, адрес, email)
- **Генерация Bitcoin-адреса** для оплаты через Bitcoin Core RPC
- **Проверка оплаты** в реальном времени (автоматически каждые 30 сек)
- **Страница успешной оплаты** с деталями заказа
- **Страница поддержки** с FAQ и контактами
- **Админ-панель** — просмотр заказов, статистика, очистка истории
- **Поддержка именованных кошельков Bitcoin Core** (BTC_WALLET)
- **Сохранение данных** в текстовые файлы (как и в боте)

## Быстрый старт

### 1. Установка зависимостей

```bash
cd website
pip install -r requirements.txt
```

### 2. Настройка

Скопируйте `.env.example` в `.env` и отредактируйте:

```bash
copy .env.example .env
```

### 3. Запуск

```bash
python app.py
```

Сайт будет доступен по адресу: **http://127.0.0.1:5000**

## 🔐 Админ-панель

Сайт имеет админ-панель для управления заказами (аналогично командам Telegram-бота `/orders`, `/stats`, `/clear_orders`).

### Настройка администраторов

В файле `.env` укажите:

```ini

# Пароль для входа в админ-панель
```
