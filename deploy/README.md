# Инструкция по деплою на VPS сервер

## Выбор VPS

| Провайдер | Цена | Особенности |
|-----------|------|-------------|
| **Timeweb** | от 250 ₽/мес | RU, простой личный кабинет |
| **FirstVDS** | от 250 ₽/мес | RU, быстрая поддержка |
| **Beget** | от 300 ₽/мес | RU |
| **Hetzner** | от 4€/мес | EU, мощный, но нужна карта |

**Минимальные требования:**
- 2 CPU, 2 GB RAM
- 50+ GB SSD (для Bitcoin Core)
- Ubuntu 22.04/24.04

## Быстрый старт (Ubuntu)

```bash
# 1. Подключиться к серверу
ssh root@IP_SERVERA

# 2. Запустить установку (делает всё автоматом)
cd /root
wget -O setup.sh https://...setup.sh
chmod +x setup.sh && ./setup.sh
```
